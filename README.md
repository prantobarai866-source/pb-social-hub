🚗 NEON PURSUIT 3D — STREET HUNTER

A browser-based 3D car driving and street pursuit game built with HTML, CSS, JavaScript, and Three.js.

🎮 About the Game

NEON PURSUIT 3D — STREET HUNTER is a lightweight 3D driving game designed to run directly in a modern web browser.

Drive through the city, avoid obstacles, control your vehicle, and experience a neon-style street environment.

✨ Features

- 🚗 3D car driving
- 🏙️ 3D city/street environment
- 🌞 Daytime environment
- 🎮 Keyboard controls
- 📱 Mobile-friendly interface
- ⚡ Smooth browser-based gameplay
- 🎨 Neon-inspired visual design
- 🌐 No installation required for the web version
- 📦 Uses Three.js for 3D rendering

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Three.js
- Tailwind CSS

🎮 Controls

Desktop

Key| Action
"W" / "↑"| Accelerate
"S" / "↓"| Brake / Reverse
"A" / "←"| Turn Left
"D" / "→"| Turn Right

Mobile

Use the on-screen controls provided by the game interface.

🚀 Running the Game

Option 1 — Open Directly

Simply open the game's HTML file in a modern browser.

index.html

Option 2 — Local Web Server

For the best compatibility, run the project through a local web server.

Example:

python -m http.server 8000

Then open:

http://localhost:8000

🌐 Browser Support

The game is intended for modern browsers that support WebGL and JavaScript.

Recommended browsers:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

📱 Mobile Support

The interface is designed to work on mobile devices as well as desktop browsers.

For better performance on lower-end phones:

- Close unnecessary browser tabs.
- Use a modern browser.
- Reduce other background applications.
- Keep the device from overheating during long gameplay sessions.
